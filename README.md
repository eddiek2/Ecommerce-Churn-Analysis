# E-Commerce Customer Churn Analysis

## Project Overview
Analysis of 5,630 e-commerce customers to identify 
key drivers of customer churn and support retention strategy.

## Tools Used
- Python (Pandas, Seaborn, Matplotlib)
- SQL (SQLite) including HAVING clauses
- Power BI (Interactive dashboard with slicers)

## Key Findings
- 16.8% overall churn rate (948 out of 5,630 customers)
- COD users churn at 28% vs 12% for Credit Card users
- Phone login users have the highest churn at 22%
- Churned customers stay only 4 months vs 11.5 for loyal customers
- Single customers have the highest churn count at 480
